Support

For Baojun head units running LingOS (Android 9). Tested on a 2025 Baojun with model code E261SPLUS.

First install

The first copy of SP Baojun Kit goes on from a computer or phone over ADB. Turn on ADB in the car's engineering mode (Settings → System → System info, tap the software version until it asks for a code), connect, then install. After that the Kit keeps itself and the launcher current.

Optional one-time grants, from the computer:

adb shell pm grant com.sp.baojunkit android.permission.WRITE_SECURE_SETTINGS
adb shell appops set com.sp.baojunkit REQUEST_INSTALL_PACKAGES allow

The first lets the Kit switch ADB on and off. The second lets it install updates without asking Android's “install unknown apps” question first.

Tapping an app on the home screen does nothing

The stock LingOS launcher can only open apps whose name it already knows. That's why the launcher is named 应用商店: the car opens it, and it opens everything else. Put it in 常用应用 (edit with the pencil) — that panel survives a restart.

My apps vanished from the home screen after a restart

LingOS shows an old saved list after a reboot and only rebuilds it when an app is installed or updated. Your apps are still there: open 应用商店 from 常用应用. The list comes back on the next install or update.

Apps hide under the top bar

The car's top bar doesn't tell Android it takes space. Apps opened from 应用商店 open in a window that fits between the bars. Don't press the window's maximise button — that makes it full-screen again. This needs freeform windows switched on once:

adb shell settings put global enable_freeform_support 1
adb shell settings put global force_resizable_activities 1

then restart the head unit.

Updates

The Kit checks every 6 hours and shortly after each start, downloads anything newer, checks its SHA‑256, and shows Android's own Install prompt. Turn Auto update off in the Kit's Updates card to stop it.
